## 🌟 نظرة عامة عن النظام (Overview)

**Smart POS** هو نظام نقاط بيع ومحاسبة سحابي متكامل ومتعدد التجار (**Multi-Tenant Cloud POS & ERP**)، مصمم خصيصاً لتلبية احتياجات المتاجر، السوبرماركت، محلات التجزئة، الصيدليات، والمطاعم في السوق العربي والمصري.

يجمع النظام بين **السرعة الفائقة في عمليات الكاشير**، **التحكم الشامل في الصلاحيات والمخزون**، **الأتمتة الكاملة للتقارير المالية**، و**لوحة تحكم إدارية عليا لإدارة الاشتراكات والتجار**.

## 💎 المميزات الجوهرية للنظام (Core Features)

### 1. 🛒 شاشة نقطة البيع السريعة (Ultra-Fast POS)
* **دعم قارئ الباركود والبحث الفوري:** إضافة المنتجات بمسح الباركود أو البحث بالاسم أو الاختيار السريع من التصنيفات المصورة.
* **اختصارات لوحة المفاتيح السريعة:**
  * `F1` : البحث السريع عن المنتجات.
  * `F2` : مسح الباركود.
  * `F4` : الدفع النقدي الفوري (Cash Quick Pay).
  * `F8` : تعليق الفاتورة الحالية.
  * `F9` : استعراض الفواتير المعلقة.
* **🛡️ حماية سعر التكلفة ومنع البيع بخسارة (Cost-Price Protection):**
  * فحص فوري وذكي لأي خصم يطبقه الكاشير (نسبة أو مبلغ).
  * حظر الخصم تلقائياً إذا أدى لهبوط سعر البيع عن سعر التكلفة المسجل للصنف لحماية أموال التاجر.
* **تعليق واستئناف الفواتير (Hold & Resume):** تعليق فواتير متعددة والرجوع إليها بمرونة دون إيقاف حركة البيع.
* **طرق دفع متعددة:** كاش، بطاقة بنكية/فيزا، آجل على حساب العميل، مع حساب فوري للباقي.
* **طباعة الإيصالات والفواتير الضريبية:** دعم الطابعات الحرارية وطابعات A4 مع دعم الشعار والباركود ورمز QR.

### 2. 📊 نظام التقارير التلقائية الذكية (Automated Reports)
* **توليد تلقائي فوري:** توليد التقرير وجلب بياناته فور فتح الصفحة بدون الحاجة للنقر على أي زر.
* **فلاتر الفترات الزمنية السريعة بنقرة واحدة:**
  * **اليوم (Daily):** مبيعات وأرباح اليوم الحالي.
  * **هذا الأسبوع (Weekly):** ملخص أداء الأسبوع الجاري.
  * **هذا الشهر (Monthly):** التقرير الشامل للشهر الحالي.
  * **مخصص (Custom Range):** تحديد فترة حرة من تاريخ إلى تاريخ.
* **حزم التقارير المدعومة:**
  * تقرير المبيعات والتحصيلات.
  * تقرير الأرباح والخسائر الفعلي (Profit & Loss).
  * تقرير حركة ورصيد المخزون وتقييم البضاعة.
  * تقرير ورديات الكاشير اليومية وإغلاق الخزينة.
  * تقرير المنتجات الأكثر مبيعاً والأعلى ربحية.
  * تقرير الفواتير الضريبية وضريبة القيمة المضافة.
  * كشوف حسابات العملاء والموردين.
  * تصدير مباشر إلى Excel / CSV و PDF.

### 3. 👥 إدارة المستخدمين والصلاحيات المتقدمة (Roles & Granular Permissions)
تحكم مطلق لمالك المتجر في تحديد ما يراه كل كاشير ومساعد بدقة:
* **شاشات القائمة الجانبية المسموحة:** (إظهار أو إخفاء: نقطة البيع، الفواتير، لوحة التحكم، المنتجات، المخزون، العملاء، الموردين، التقارير).
* **التقارير المخصصة للكاشير:** إمكانية السماح للكاشير برؤية تقارير محددة فقط (مثل الوردية والمبيعات) وحجب تقرير الأرباح والخسائر والضرائب.
* **صلاحيات العمليات التشغيلية:**
  * إتمام البيع.
  * تطبيق الخصومات.
  * تعليق واسترجاع الفواتير.
  * عمل المرتجعات.
  * إلغاء الفواتير.
  * فتح درج النقدية يدوياً.
  * إظهار أو حجب سعر التكلفة والأرباح عن شاشة الكاشير.

### 4. 📦 إدارة المنتجات والمخزون المبسطة (Products & Inventory)
* **إضافة سريعة للصنف:** التركيز على الحقول الأساسية: اسم المنتج، سعر البيع، وسعر التكلفة، مع حساب هامش الربح المتوقع فوراً.
* **توليد تلقائي للباركود وكود الصنف (SKU):** بضغطة زر واحدة أو تلقائياً في حال تركها فارغة.
* **رقم الهاتف هو المعرف الأساسي:** لا يُلزم التاجر أو العميل أو المورد أو الكاشير بإدخال بريد إلكتروني.
* **مستودعات متعددة:** تتبع المخزون عبر عدة فروع ومستودعات، مع دعم التحويلات الداخلية وتعديلات الجرد والتسوية.
* **تنبيهات نواقص المخزون:** إشعارات فورية بالأصناف التي أوشكت على النفاد للطلب المبكر من الموردين.

### 5. 👑 لوحة تحكم المشرف العام (Super Admin Dashboard)
* **إدارة التجار (Tenants):** تسجيل المتاجر الجديدة بسهولة باستخدام رقم الهاتف واسم المتجر، وتفعيل أو إيقاف الحسابات.
* **باقات الاشتراك المبسطة (Plans):** تسعير بالجنيه المصري (ج.م) وتحديد عدد الكاشير المسموح به وعدد الفروع، مع حدود لا نهائية للميزات الأخرى افتراضياً.
* **تذاكر الدعم الفني (Support Tickets):** متابعة طلبات التجار والرد الفوري عليها.
* **مراقبة صحة النظام:** متابعة السيرفر واستخدام الموارد وقاعدة البيانات.

### 6. 📱 تجربة PWA والعمل بدون إنترنت (Offline First)
* تثبيت كبرنامج تطبيقي مستقل على أجهزة Windows, macOS, Android, و iOS.
* تخزين محلي آمن للبيانات عبر IndexedDB لمواصلة البيع السريع حتى عند انقطاع اتصال الإنترنت، مع مزامنة تلقائية فور استعادة الاتصال.

## 🔑 أدوار المستخدمين وصلاحيات الوصول (User Roles)

| الدور (Role) | الوصف ونطاق الصلاحية |
| :--- | :--- |
| `SUPER_ADMIN` | المشرف العام مالك المنصة (إدارة التجار، الباقات، النظام، الدعم الفني). |
| `ADMIN` | مدير عام المتجر / التاجر (صلاحية كاملة على المتجر والفروع والإعدادات). |
| `MANAGER` | مدير فرع (إدارة المبيعات والمخزون والكاشير داخل الفرع). |
| `CASHIER` | كاشير / بائع (شاشة نقطة البيع مع الصلاحيات والتقارير المحددة له بدقة من التاجر). |
| `ACCOUNTANT` | محاسب (القيود، التقارير المالية، الضرائب، كشوف الحسابات). |
| `INVENTORY_STAFF` | أمين مخزن (أوامر الشراء، الجرد، التحويلات، استلام البضائع). |
| `VIEWER` | مشاهد فقط (للاطلاع دون إجراء أي تعديل). |

## 💻 متطلبات التشغيل والتثبيت (Getting Started)

### المتطلبات الأساسية (Prerequisites)
* **Node.js** إصدار `>= 20.0.0`
* **pnpm** إصدار `>= 9.0.0`
* **PostgreSQL** إصدار `>= 16`
* **Redis** إصدار `>= 7`

---

### خطوات التثبيت والتشغيل المحلي (Local Setup)

1. **استنساخ المستودع (Clone Repository):**
   ```bash
   git clone https://github.com/AbdullahTamer47/Smart-POS-v2.git
   cd Smart-POS-v2
   ```

2. **تثبيت الاعتماديات (Install Dependencies):**
   ```bash
   pnpm install
   ```

3. **إعداد متغيرات البيئة (Environment Variables):**
   ```bash
   cp .env.example .env
   ```
   *قم بتعديل قيم الاتصال بقاعدة البيانات وJWT بما يناسب بيئتك المحلية.*

4. **تشغيل الخدمات عبر Docker (اختياري وسريع):**
   ```bash
   docker compose up -d postgres redis
   ```

5. **تطبيق ترحيل قاعدة البيانات والبيانات الأولية (Migrate & Seed):**
   ```bash
   pnpm run db:migrate
   pnpm run db:seed
   ```

6. **بدء وضع التطوير لكامل المشروع (Start Development):**
   ```bash
   pnpm run dev
   ```

* **رابط الواجهة الأمامية:** `http://localhost:5173`
* **رابط الخادم والـ API:** `http://localhost:3000`
* **توثيق Swagger التفاعلي للـ API:** `http://localhost:3000/api/docs`

## 🛠️ الأوامر المتاحة في المشروع (Available Scripts)

### الأوامر العامة (Root Scripts)
* `pnpm run dev` : تشغيل كافة تطبيقات المنظومة في وضع التطوير التفاعلي.
* `pnpm run build` : بناء حزم الإنتاج لجميع التطبيقات والمكتبات.
* `pnpm run typecheck` : التحقق الشامل من سلامة أنواع TypeScript بدون أخطاء.
* `pnpm run lint` : فحص الكود وتنسيقه وفق معايير ESLint.
* `pnpm run test` : تشغيل اختبارات الوحدة.
* `pnpm run clean` : تنظيف ملفات البناء المؤقتة ومجلدات `dist`.

### أوامر الواجهة الأمامية (`apps/frontend`)
* `pnpm --filter @smartpos/frontend dev` : تشغيل سيرفر Vite للواجهة.
* `pnpm --filter @smartpos/frontend build` : تجميع حزمة الإنتاج في مجلد `dist`.
* `pnpm --filter @smartpos/frontend preview` : معاينة حزمة الإنتاج محلياً.

### أوامر الخادم الخلفي (`apps/backend`)
* `pnpm --filter @smartpos/backend dev` : تشغيل خادم NestJS مع ميزة المراقبة والتحديث الفوري.
* `pnpm --filter @smartpos/backend build` : تجميع كود الباك إند للإنتاج.
* `pnpm --filter @smartpos/backend start` : تشغيل الخادم المبني للإنتاج.
* `pnpm --filter @smartpos/backend db:migrate` : ترحيل التحديثات إلى قاعدة بيانات PostgreSQL.

## 🌐 النشر السحابي (Deployment)

### النشر على Vercel (Frontend)
الواجهة الأمامية مهيأة بالكامل للنشر الفوري على **Vercel** كـ SPA مع تضمين قواعد إعادة التوجيه في `vercel.json`:
```bash
# بناء حزمة الإنتاج أولاً
pnpm --filter @smartpos/frontend build

# النشر الفوري
npx vercel deploy apps/frontend/dist --yes
```

### النشر الكامل عبر Docker (Full Stack)
يحتوي المشروع على ملف `docker-compose.yml` متكامل لتشغيل الواجهة الأمامية، الخادم الخلفي، قاعدة البيانات، Redis، ومخدم Nginx بضغطة واحدة:
```bash
docker compose up -d --build
```
